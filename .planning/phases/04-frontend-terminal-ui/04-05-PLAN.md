  <action>
    ChatPanel.tsx: a `'use client'` component. Props: `onActions(): void` (parent re-fetches portfolio + watchlist after the assistant executes actions). Local state: an in-memory list of messages ({role:'user'|'assistant', content, actions?}), the input text, a `loading` boolean, and a `collapsed` boolean. Render a docked sidebar with a header + collapse/expand toggle; when collapsed, show only a compact tab/button to reopen. Body: a scrolling message list (auto-scroll to the newest message) and an input row (textarea/input + Send). On Send: append the user message locally, set loading true, POST via `api.sendChat(text)`; on success append the assistant message with its `actions`, render each action inline as a confirmation chip (green up token for status 'ok', red down token for 'error') showing e.g. "Bought 10 AAPL @ 190.50" / "Added PYPL to watchlist" / the error detail; then, if `response.actions.length > 0`, call `onActions()`. On failure append an assistant-style error bubble with the thrown detail. Always clear loading in a finally. Show a loading indicator (e.g. animated dots) in the message list while awaiting the response. IMPORTANT: render all message content and action detail as React text nodes only — never use dangerouslySetInnerHTML (assistant/user text is untrusted; see threat_model T-04-09).
