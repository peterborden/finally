<objective>
Build the left-column Watchlist grid and the center Main PriceChart. The watchlist flashes prices green/red on change (UI-02), shows daily change % and a hand-rolled progressive SVG sparkline accumulated from SSE, and supports add/remove plus row-selection. Clicking a row selects the ticker for the PriceChart, a lightweight-charts line built from that ticker's accumulated ticks since page load (UI-03).

Purpose: These are the two most visible live-data surfaces of the terminal — the streaming watchlist and the selected-ticker chart.

Output: `Watchlist.tsx`, `Sparkline.tsx`, `PriceChart.tsx` components consumed by the page assembly in 04-06.
</objective>
