## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → API | Untrusted HTTP requests cross into FastAPI routes and static serving |
| env → filesystem | FRONTEND_DIST / FINALLY_DB_PATH control served directory and DB location |
| package registry → build | New dev dependency (httpx) pulled from PyPI |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-APP-01 | Information Disclosure | StaticFiles mount at '/' | medium | mitigate | Use framework `fastapi.staticfiles.StaticFiles` (blocks ../ path traversal); serve only the resolved frontend dir, never a parent |
| T-01-APP-02 | Tampering / Spoofing | route precedence (static shadowing /api) | medium | mitigate | Register /api/health and the SSE router BEFORE mounting StaticFiles at '/'; test asserts /api/* is not served by the static catch-all |
| T-01-APP-03 | Denial of Service | lifespan market-source start failure | low | accept | Start/stop wrapped with logging; a source failure logs and does not wedge the app; SSE generator already handles client disconnect |
| T-01-SC | Tampering (supply chain) | httpx dev dependency install | high | mitigate | Blocking human-verify checkpoint confirms httpx on pypi.org before install; pinned `httpx>=0.27.0`; dev-only, recorded in uv.lock |
</threat_model>
