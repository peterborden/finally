## Directory Purposes

**`backend/`:**
- Purpose: Complete FastAPI backend application
- Contains: Python source code, tests, project configuration
- Key files: `pyproject.toml`, `uv.lock`
- Managed by: Backend/Market Data agents

**`backend/app/`:**
- Purpose: Application package namespace
- Contains: All server logic organized by feature/subsystem
- Currently: Only `market/` subsystem is implemented
- Future: `portfolio.py`, `chat.py`, `database.py`, `models.py` (SQLAlchemy), `routes.py`, `main.py` (FastAPI app)

**`backend/app/market/`:**
- Purpose: Market data subsystem — responsible for sourcing, caching, and streaming prices
- Contains: Simulator, Massive API client, cache, SSE endpoint, data models
- Depends on: `numpy`, `massive` SDK (optional), `fastapi`
- Used by: SSE consumers, (future) portfolio valuation, (future) trading engine

**`backend/tests/`:**
- Purpose: Test suite mirroring `app/` structure
- Contains: Unit tests, integration tests, fixtures
- Pattern: Pytest with `pytest-asyncio` for async tests
- Run: `uv run pytest` from `backend/`

**`planning/`:**
- Purpose: Project-wide documentation for all agents
- Contains: Requirements, architecture, implementation guides, meeting notes
- Key docs: `PLAN.md` (full spec), `MARKET_DATA_SUMMARY.md` (completed subsystem)

**`.planning/codebase/`:**
- Purpose: Generated codebase analysis documents
- Contains: ARCHITECTURE.md, STRUCTURE.md, CONVENTIONS.md, TESTING.md, STACK.md, INTEGRATIONS.md, CONCERNS.md
- Generated by: `/gsd-map-codebase` orchestrator
- Updated: Before each phase planning, when significant changes made

## Naming Conventions

**Files:**
- Source files: `snake_case.py` (e.g., `price_cache.py`, `market_data_source.py`)
- Test files: `test_<module>.py` (e.g., `test_cache.py`, `test_simulator.py`)
- Demo files: `<feature>_demo.py` (e.g., `market_data_demo.py`)
- Config files: `pyproject.toml`, `conftest.py`, `CLAUDE.md`, `README.md`

**Directories:**
- Package: `snake_case` (e.g., `app/`, `backend/`, `market/`, `tests/`)
- Feature subsystems: `snake_case` (e.g., `market/`, future: `portfolio/`, `chat/`)

**Classes:**
- All classes: `PascalCase` (e.g., `PriceCache`, `PriceUpdate`, `MarketDataSource`, `SimulatorDataSource`, `GBMSimulator`, `MassiveDataSource`)

**Functions/Methods:**
- All: `snake_case` (e.g., `update()`, `get_tickers()`, `_run_loop()`, `create_market_data_source()`)

**Variables/Constants:**
- Local variables: `snake_case`
- Constants: `UPPER_CASE` (e.g., `TRADING_SECONDS_PER_YEAR`, `DEFAULT_DT`, `SEED_PRICES`, `CORRELATION_GROUPS`)

**Tests:**
- Test classes: `Test<Feature>` (e.g., `TestPriceUpdate`, `TestPriceCache`, `TestSimulatorDataSource`)
- Test methods: `test_<scenario>` (e.g., `test_price_update_creation()`, `test_update_and_get()`, `test_start_populates_cache()`)

## Where to Add New Code

**New Feature (e.g., Portfolio Management):**
- Implementation: `backend/app/portfolio.py` or `backend/app/portfolio/` package
- Tests: `backend/tests/portfolio/test_*.py`
- If interacting with database: `backend/app/models.py` (SQLAlchemy ORM)

**New Component/Module:**
- If part of market subsystem: `backend/app/market/<component>.py`
- If new subsystem: Create directory `backend/app/<feature>/` and organize like `market/`
  - Public API in `backend/app/<feature>/__init__.py`
  - Implementation in `backend/app/<feature>/<module>.py`
  - Tests in `backend/tests/<feature>/test_*.py`

**Utilities/Helpers:**
- Shared helpers: `backend/app/utils.py` or `backend/app/utils/<module>.py`
- Validators: `backend/app/validators.py`
- Exceptions: `backend/app/exceptions.py`

**Frontend:**
- All frontend code: `frontend/` (Next.js, TBD)
- Structure managed by Frontend agent, but expect:
  - `frontend/src/` or `frontend/app/` (Next.js 13+ app directory)
  - `frontend/components/` - React components
  - `frontend/pages/` or `frontend/api/` - Routes
  - `frontend/styles/` - CSS/Tailwind config

**Tests:**
- Unit tests: `backend/tests/<feature>/test_<module>.py`
- Integration tests: Same file as unit tests, marked with `@pytest.mark.asyncio` or in separate `test_<module>_integration.py`
- E2E tests: `test/` directory (not yet created) with Playwright/Docker

- Purpose: Claude Code harness configuration and skills

- Committed: Yes, to git
